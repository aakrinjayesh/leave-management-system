Employee Portal Handbook

Every flow in the portal, end to end — who logs in, what each role sees, how leave and timesheets move through approval, and exactly how a payslip is built.

Covers: leave · timesheets · WFH · attendance · resignation · payroll Fiscal year: April – March
01

Roles & access

Every account has one account type — Employee, Manager, or Admin — but day-to-day permissions are decided by two things working together:

Account type
Employee / Manager / Admin. Set by an admin. Admin is the only type with system-wide reach.
Is a manager?
Derived, not stored — true whenever at least one person has picked this account as their reporting manager. Any account, Admin included, gains the manager screens the moment someone reports to them, and loses them when nobody does.
Employment type
Employee / Intern / Contract. A label only — it changes the badge shown and, for Contract, swaps payroll to a separate flat model. Interns and contractors otherwise use the identical leave / timesheet / WFH flows.
In this document

Role tags mark who a paragraph or row applies to: EMPLOYEE MANAGER ADMIN

Accounts are created by an admin from Manage Accounts → Add account. Employee accounts must use the company email domain; a Hire-to-Contract account may be given an outside email. A new account starts Pending until the person activates it.

02

Signing in

First time — activation

  1. Open the activation page and enter your work email.
  2. Verify the code emailed to you (one-time password).
  3. Set a password. The account flips from Pending to Active and you land on your dashboard.

Every time after

Sign in with email + password, or choose Sign in with a code to get a one-time password by email instead. Forgot password runs the same email → code → new password sequence.

04

Leave

The leave types

TypeAnnualHalf dayPer requestRules that bite
Casual Leave12yes5 days> 4 days needs 20 days’ notice; weekend between two leave days in one request is also charged (“sandwich rule”)
Sick Leave8yes2 daysonly today / tomorrow; > 2 days needs a supporting document (then up to 7)
Earned Leave15yes15 daysfor longer planned breaks
Unpaid Leave∞no30 dayssalary is deducted per day — this is Loss of Pay (see §10)

Allocations and rules are the defaults; an admin edits them in Manage Leave Policy.

Balances & carry-forward

By default a paid type’s full annual allowance is available from the start of the fiscal year (April). An admin can switch a type to monthly accrual, in which case days are credited gradually and whatever you don’t use keeps rolling forward — nothing resets between months, only at the next fiscal year, when a fresh balance starts from zero.

Applying — EMPLOYEE MANAGER ADMIN

  1. My Leave Requests → Apply for leave. Pick the type, the dates, half-day if it’s a single day, and a reason. Attach a document if the type needs one.
  2. The portal checks the rules — past-date block, the 90-day forward window, the per-type limits above, and that the dates don’t overlap existing leave or an approved WFH.
  3. Balance is worked out. If the request fits, it’s booked under that type. If it doesn’t: an accrual-configured type auto-books the excess days as Unpaid Leave so the request still goes through; other types are blocked until you shorten it.
  4. It routes to your manager and shows as Pending. You’ll be notified on the decision.
Who approves

Your assigned manager, or any admin (from All Leave Requests). You can cancel a request only while it’s still Pending.

Logged, not requested

A manager (for a direct report) or an admin (for anyone) can log leave on someone’s behalf — it’s recorded already approved, skipping the notice-period and past-date guards. Balance and double-booking are still enforced.

Holidays added later

If an admin adds a company holiday that falls inside an approved leave, that leave is automatically trimmed or cancelled and the balance refunded.

05

Timesheets

Timesheets are per project. Each project submits either weekly (Mon–Sun) or monthly, set by the admin. Someone on three projects fills three separate grids.

Filling & submitting — EMPLOYEE MANAGER ADMIN

  1. Timesheet tab → pick the project. Enter hours (and an optional note) for each working day. Weekends, holidays and approved full-day leave are locked; a half-day leave caps that day at half.
  2. Client project? Upload that period’s Excel sheet (.xls / .xlsx). Internal projects don’t need one — the hours grid submits on its own.
  3. Save keeps a draft you can keep editing. Submit sends the period to your manager and locks it.
  4. Manager or admin approves. A rejection reopens the exact same period — fix it and resubmit into the same row.
Once submitted, it’s locked

A Pending timesheet can’t be edited, and there is no self-withdraw. If you spot a mistake before it’s actioned, ask your manager or an admin to reject it so it reopens.

Your uploaded sheet

An uploaded-but-not-yet-submitted Excel sheet is remembered per project + period, so switching tabs or refreshing doesn’t lose it. View opens it in a browser viewer; Download saves the file.

Logged on behalf

MANAGER (direct reports) / ADMIN (anyone) can log a whole period from the Log timesheet button — it’s recorded auto-approved. Same Excel rule: required for client projects, not internal.

06

Work from home

  1. WFH tab → new request. Give a date range and a reason. You must be on at least one project, and you can only have one pending request at a time.
  2. Checks: the range must contain a working day, and can’t overlap an approved leave.
  3. Decision: ADMIN (from All WFH Requests) or the employee’s MANAGER (from Team WFH) approves or rejects.
After the fact

You can withdraw a request while it’s pending. An admin can revoke one that was already approved (for example, if plans change to leave).

07

Reimbursements

An expense claim runs on the same rails as a leave request — EMPLOYEE MANAGER ADMIN can all file their own.

  1. Reimbursements tab → New claim. Give a subject, a description, the amount, and attach at least one receipt or invoice (several are allowed — PDF, image, Word, Excel or CSV).
  2. It routes to your manager and shows as Pending. If you have no manager it goes straight to the admins.
  3. Your manager or any admin approves or rejects it. A rejection always needs a reason, which then shows against the claim in your history.
Cancel & log-on-behalf

You can cancel a claim while it’s still Pending. A manager (for a direct report) or an admin (for anyone) can log a claim on someone’s behalf from the Team / All Reimbursements page — recorded auto-approved, attachment still required.

No payment tracking

Approved is the final state — the portal doesn’t track when the money is actually paid out. And you can never approve your own claim.

08

Attendance

Attendance is a self-reported, per-project daily log — there is no approval and no on-time / late judgement. Each day you get a control per project: Present or Half day.

  • Weekend, holiday, on-leave and WFH days are shown automatically — you never mark those.
  • You can mark or fix any working day from the tracking start (or your joining date, whichever is later) up to today. Earlier days can only be corrected by an admin.
  • The dashboard’s Today’s attendance card and the amber reminder strip are shortcuts to the same thing.
09

Resignation

  1. Profile → submit resignation with a reason and a proposed last working day. One active resignation at a time; you can withdraw it while pending.
  2. Your manager sees it on Team Resignations — view only.
  3. An admin accepts or rejects from All Resignations. On acceptance the confirmed last working day is set to proposed date + notice period (90 days by default).
After acceptance

Once a resignation is accepted the employee can no longer apply for new leave. A manager or admin can still log leave on their behalf if needed.

10

Payslips & Loss of Pay

Salary structure — ADMIN

Each employee has a CTC and a salary structure set by an admin (Manage Accounts → employee details → Salary). The structure is a set of percentages — Basic as a % of CTC, HRA / LTA / guaranteed allowance as a % of Basic — plus flat amounts for conveyance, PF and professional tax. Changes are dated (effective from) and the history is kept, so a payslip always uses the structure that applied that month.

Generating a payslip

Payslips are not automatic. From Payslips → an employee → a month, the admin previews the computed figures, enters TDS and any one-time annual bonus, and confirms. A PDF is produced and stored; the employee can view it on their Profile, or the admin can email them a link.

How the monthly figure is built

From annual CTC to net pay
monthly CTC = annual CTC ÷ 12 Basic = monthly CTC × basic% HRA, LTA, g.allow = Basic × their own % special allowance = monthly CTC − (all of the above + conveyance + employer PF) Gross earnings = Basic + HRA + LTA + conveyance + g.allow + special Standard days = working days in the month (weekends & holidays out) per-day rate = Gross earnings ÷ Standard days LOP amount = per-day rate × LOP days Gross pay = Gross earnings + annual bonus Deductions = employee PF + professional tax + TDS + LOP amount Net pay = Gross pay − Deductions

LOP days = approved Unpaid Leave working days that fall in the month, plus (in your joining month only) any working days before you started. Everything you take beyond your paid balance becomes Unpaid Leave, which is what feeds this.

Contract hires

Employment type Contract uses a separate model — a flat Gross − TDS with no structure, PF or LOP — on its own screens.

A separate income-tax computation (projected annual tax, old vs new regime) is available per employee and on each person’s Profile.

ADMIN self-service — “My Workspace”

Admins don’t get the personal tabs in the sidebar. Instead the My Workspace card on the dashboard links them to their own leave, timesheet, WFH and attendance. Their requests route to their assigned manager (if they have one) and can be actioned by that manager or any other admin — an admin can never approve their own. Admins are also full participants in payroll: they have a CTC and structure and appear in the Payslips list like anyone else. Resignation is intentionally excluded.

The admin toolbox

Everything in this section is ADMIN only. The company-wide All Leave Requests / All Timesheets / All Calendar / All Attendance / All WFH Requests / All Resignations / All Reimbursements screens let an admin see and action any employee’s requests regardless of reporting line — those flows are covered in §04–10 and the matrix below. What follows is the setup and back-office side.

Manage Accounts

The master list of every account, searchable by name, with a headline count of total accounts, employees and manager-tier accounts. Per account:

ActionWhat it does
Add accountName, work email, account type, employment type. Hire-to-Contract may use an outside email; Employee / Intern must use the company domain. The account starts Pending until activated.
Set managerAssign or change who this person reports to — this is what gives that manager their team screens.
Make admin / Remove admin accessGrant or revoke the Admin account type. Can’t remove the last active admin.
Employment typeSwitch between Employee and Intern. Contract is fixed once set.
View detailsThe full record — personal, statutory (PAN / Aadhaar / UAN), bank, employee code, custom fields, uploaded documents, and the salary structure & CTC history. An admin can edit any of it directly.
Upload / Replace / View documentAttach a file (offer letter, ID, contract…) to the account.
Timesheet / Leave detailsJump into that person’s timesheet or leave record to view history or log an entry on their behalf.
Offer letterDraft, preview and download an offer-letter PDF for a candidate.
ExitRecord an exit date + relieving-letter text; a relieving letter PDF is generated. Reactivate restores an exited account; Download letter re-fetches the relieving letter later.

Project

Projects drive timesheets, attendance and the client-vs-internal distinction.

  • Create / edit a project — name, type (Client or Internal), client name (admin-only, never shown to employees), submission frequency (weekly or monthly), timezone, working hours, start date and optional end date. Members inherit all of these automatically.
  • Manage members — add or remove anyone (admins included), each with their own start date and optional end date on the project. A hint lists people who have logged time against the project but aren’t formally on it yet.
  • Deactivate / reactivate a project.
  • Reports — a project-assignment report (who is on what, who is on nothing), per-project employee timesheets, a per-person project history, and a weekly timesheet-submission report.

Report — the payroll register

A chosen month’s payroll register: every employee’s payslip figures in one table, with a monthly or cumulative (year-to-date) view, and a separate scope for contract hires. Read-only — it’s assembled from the payslips that have been generated.

Manage Leave Policy

AreaWhat an admin controls
Leave typesAdd or edit a type — annual allocation, monthly accrual on / off, half-day allowed, max days per request, advance-booking limit, long-request notice rule, document-required threshold, unlimited / unpaid flags, description. Deactivate a type to retire it. Past fiscal years’ policies stay viewable.
HolidaysAdd a single day or a date range (up to 31 days), mark it optional, edit or retire it, and browse by year. Adding a holiday that overlaps approved leave or WFH auto-adjusts those.
Company settingsThe fiscal-year start month (April by default) — this decides how leave balances and payroll bucket into years.

Payslips

Per employee, per month:

  • Set and revise the salary structure & CTC — dated effective from, with full history.
  • Preview the computed payslip, enter TDS and any one-time bonus, then generate — a PDF is produced and stored.
  • Email the employee a link to their payslip, or download the PDF.
  • Generate a projected income-tax computation (annual, old vs new regime) from the employee’s tax declaration.
  • Contract hires get their own contract-payment structure and payment PDFs on the same screen.
